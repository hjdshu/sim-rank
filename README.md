## 系统简介

赛车圈速排行榜是一个纯前端单 HTML 文件应用，用于记录和展示多赛道的赛车圈速数据。无需服务器，双击打开即可使用。

**特点：**
- 纯 HTML 单文件，无任何依赖
- 数据按文件路径隔离存储，复制多份互不干扰
- 9 种预设主题
- 管理员密码保护
- 多赛道、多车型管理
- 时间维度筛选（日/周/月/年榜）

---

## 快速开始

### 1. 打开文件
直接在浏览器中双击打开 `排行榜.html` 即可。推荐使用 Chrome / Edge / Firefox。

### 2. 添加第一条记录
1. 点击页面底部的 **"管理数据"** 按钮
2. 在顶部的添加栏中依次填写：车手姓名、圈速（分:秒:毫秒）、赛道、车型、日期
3. 点击 **"添加"** 按钮
4. 记录自动出现在排行榜中，按圈速排序

### 3. 切换赛道
在页面顶部的赛道选择器中切换，排行榜会显示对应赛道的记录。

## 排行榜界面

### 排名显示
- 第 1 名：主题色高亮 + 发光效果，圈速文字为紫色
- 第 2 名：次级高亮
- 第 3 名：三级高亮
- 其余名次：普通显示

每条记录显示：排名、车手姓名、圈速、赛车型号、日期。

### 时间筛选
排行榜标题栏右侧有时间维度切换：
- **总榜**：所有记录
- **日榜**：当天记录
- **周榜**：最近 7 天
- **月榜**：最近 30 天
- **年榜**：最近 365 天

### 页面宽度
页面底部可以选择：
- **全屏**：占满整个屏幕
- **自定义**：设置固定宽度（800-3840px）

## 管理数据

点击 **"管理数据"** 按钮打开管理面板（如设置了密码需先输入）。

### 添加新记录

添加栏为一行紧凑布局，从左到右依次是：

| 字段 | 说明 |
|------|------|
| 车手姓名 | 输入车手名字 |
| 分:秒:毫秒 | 圈速时间，如 1:33:999 |
| 赛道 | 选择目标赛道（可以给任意赛道添加） |
| 车型 | 选择赛车型号 |
| 日期 | 可选，默认今天 |
| 添加 | 提交记录 |
| 重置 | 清空表单 |

### 编辑记录

在"现有记录"列表中，每条记录右侧有 **编辑** 和 **删除** 按钮。

- **编辑**：弹出编辑弹窗，可修改车手姓名、圈速、车型、日期，保存后自动更新排行榜
- **删除**：删除该条记录（需确认）

### 筛选记录

现有记录上方有筛选器：
- **筛选赛道**：按赛道过滤
- **筛选车型**：按车型过滤
- 支持组合筛选，点击 **"清除筛选"** 重置

## 赛道管理

切换到 **"赛道管理"** 标签。

- **添加**：输入赛道名称，点击"添加赛道"
- **删除**：点击对应赛道的"删除"按钮

> 注意：删除赛道会同时删除该赛道的所有记录，且至少需要保留一个赛道。

---

## 车型管理

切换到 **"车型管理"** 标签。

- **添加**：输入车型名称，点击"添加车型"
- **删除**：点击对应车型的"删除"按钮

> 删除车型不会影响已有记录，但已删除车型的记录不会再出现在车型下拉列表中。

## 外观设置

切换到 **"外观设置"** 标签。

### 排行榜标题
可自定义排行榜标题文字，留空则自动显示当前赛道名称。

### Logo 设置
- **自定义文字**：在"Logo 文字"输入框中输入自定义文字，点击"更新Logo"
- **自定义图片**：在"Logo 图片地址"输入框中输入图片 URL（支持在线链接或本地路径），点击"更新Logo"。图片优先于文字显示
- **恢复默认**：点击"恢复默认"按钮，恢复显示默认的 "JAKE RACING" 文字

### 颜色主题

9 种预设主题，点击即可切换：

| 主题 | 说明 |
|------|------|
| 经典红色 | 默认主题 |
| 科技蓝色 | 蓝色系 |
| 竞速绿色 | 绿色系 |
| 神秘紫色 | 紫色系 |
| 活力橙色 | 橙色系 |
| 冠军金色 | 金色系 |
| 极光青色 | 青色系 |

## 数据存储说明

### 存储方式
所有数据保存在浏览器的 **localStorage** 中。

### 文件路径隔离
系统使用文件路径作为存储前缀，这意味着：
- `排行榜.html` 和 `排行榜2.html` 各自独立，数据互不干扰
- 复制文件到不同目录后，每份文件都是独立的排行榜
- 重命名或移动文件后，相当于一个全新的空排行榜（原数据仍在浏览器中，只是 key 对不上了）

### 容量
- localStorage 通常 5MB，约可存 **25,000 条**记录
- 正常使用完全不用担心容量问题

## 常见问题

### Q: 数据会丢失吗？
不会，除非手动清除浏览器数据或更换浏览器/设备。

### Q: 复制了一份 HTML 文件，数据会共享吗？
不会。只要文件名或路径不同，数据就是独立的。

### Q: 忘记管理员密码怎么办？
打开浏览器开发者工具（F12），在 Console 中执行：
```javascript
// 查看当前文件的存储前缀
const prefix = location.pathname + '::';
localStorage.removeItem(prefix + 'adminPassword');
```
刷新页面后密码即被清除。

### Q: 可以在移动端使用吗？
可以，排行榜会自适应屏幕。管理面板在小屏幕上可能需要滚动，建议在平板或电脑上操作。

### Q: 如何备份数据？
1. 打开浏览器开发者工具（F12）
2. 进入 Application → Local Storage
3. 找到以你文件路径开头的所有键值对，复制保存
